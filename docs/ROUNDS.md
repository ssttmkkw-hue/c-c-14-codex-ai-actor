# 迭代记录

## Round 1 · 研究、设计与首版

- 阅读 kk 的三个剧场仓库和面部表情、普通话口型、动作节奏的一手资料，整理于 [研究笔记](RESEARCH.md) 和 [设计文档](DESIGN.md)。
- 搭建月下花园和两位程序化 3D 演员。完成九种可混合情绪、独立眉眼和唇形、眨眼与扫视、呼吸、手势、下跪和同台倾听。中文自译示例、即兴表演和多行剧本共用一条可拖动的时间线。加入自动镜头、灯光与可选本地朗读。
- `npm run build` 和四条 `npm test` 均通过。用 Chromium 在端口 5814 的仓库子路径验证生产构建、播放到结尾、暂停、定位、静音字幕、三种自动镜头、剧本校验、即兴表演、灯光切换和窄屏。检查了渲染截图，调整了眼睑阴影、头发边缘、机位留白、移动端裁切和软件渲染分辨率。
- `/workspace/codex-actor-shots/` 保存 21 张 `r1-*.png`。包括九种情绪特写、朱丽叶肖像、罗密欧第一句的八帧序列、舞台全景、控制面板及手机布局。八帧覆盖准备、展唇、开口、闭唇、中间口形、圆唇及回落。
- 最终全景测得 **29.4 FPS**。Playwright 页面在 1440 × 1040 视口播放场景，5.033 秒内计数 148 次 `requestAnimationFrame`，约 183 个绘制调用。SwiftShader 使用软件 GL，适合作为保守基线。软件路径播放时将渲染比例降至 0.58，暂停时升至 1.5。较早的软件渲染复测为 14.8 与 22.3 FPS，帧率会随机器负载浮动。
- 已知限制。口型时长按字音和标点估算。系统朗读依赖本地中文语音，边界事件的精度由引擎决定。本机没有中文音色，语音开关、定位和取消用模拟引擎验证。演员采用程序化关节和布料造型，快速遮挡、唇齿贴合、手和身体接触是后续打磨重点。实际硬件 GPU 帧率尚未测量。

## Round 2 critique

- 重跑首轮截图后，特写里最廉价的是脸。眼白、肤色眼缘和虹膜像三张剪贴纸，闭眼时尤其明显。眉毛在悲伤、惊讶和朱丽叶的特写里钻进发际线，演员最需要用眉毛做事的时候反而丢了信号。发束像几根抛光的粗橡胶条，梳痕又像贴在表面的亮线。两张脸共享一张圆鼓鼓的面具，几乎要靠衣服辨认角色。
- 嘴唇像两条描了边的软管，放松时也露着一截白线。嘴张到最大时，一条整片的牙带飘在黑洞边缘。惊讶和恐惧只剩瞪圆的白眼与张嘴，厌恶像偏头打哈欠，喜悦像卡住的齿轮。光色给同一张脸染红或染蓝，掩盖了真正需要区别的眼睑、眉心与下颌动作。
- 三座细拱、粉色碎石状的花、平铺的山形和正中的亮月抢夺同一层注意力。广角和特写看起来像同一张布景往前挪，明月恰好悬在演员的发际旁。平台像摆在黑背景上的展示转盘。罗密欧的鞋被字幕遮住，朱丽叶的栏杆只在身后，二人像分别站在两个展座，缺少相互看见的空间关系。
- 台词八帧中，面部构图有变化，躯干却像固定在同一个架子上。伸手先看到持续外翻的肘，再看到垂下的腕，手指没有给出明确的意图。朱丽叶几帧里手臂垂直、脸朝观众，即使该被吸引也看不出在听谁。控制台排列整齐，但默认字幕压住鞋和台步，舞台不能单独看动作，手机上的长字幕和完整场景争同一块空间。

## Round 2 · 面部、舞美与表演修订

- 重塑两位演员的面部轮廓与发型。眼睑沿弧面覆盖虹膜，边缘和唇色渐入皮肤。眉毛避开发际线，脸颊、鼻翼和下颌随表情变形。收紧静息唇缝，减少露齿，把惊讶的圆口和恐惧的横向拉伸分开。表情图谱使用独立背景与较统一的主光，方便对照。
- 将夜景从紫色剪影调整为有薄雾的青蓝色城景，加入斜月光和舞台灯笼。全景露出脚、台步和单膝落地，中景检视手势与搭档的反应，现场特写转入视线内侧。重新布置肩肘和掌心，伸手能看到从收拢到递出再回落。增加同台的目光、迟发点头和出声时的躯干重音。
- 普通话口型在字音、闭唇和标点之间连续插值，补充少数多音字搭配和圆唇韵母。逐字提示移到可收起的字幕栏，按短句换行。增加 1/24 秒键盘步进、百分秒时间码，以及窄屏开演后回到舞台的操作。
- 在 5814 端口的仓库子路径验证生产构建。 `npm run build` 与 5 项 `npm test` 通过。Playwright 检查了静音播放、暂停和结束、拖动与逐帧、字音与高亮、字幕切换、自动镜头、灯光、即兴表演、剧本校验及 390 像素宽页面。已逐组打开 PNG 确认构图和动作。
- `/workspace/codex-actor-shots/` 保存 25 张 `r2-*.png`。包括 9 种情绪、朱丽叶肖像、同一句的 8 帧和 6 种口型状态、双人全景、控制台、窄屏、单膝跪地、双手抱头，以及同一句台词在相同机位与灯光下的两组情绪混合。
- 同一 SwiftShader 参数、1440 × 1040 视口和 0.58 播放渲染比例下，重跑首轮测得 **25.8 FPS**（130 帧 / 5.033 秒，183 个绘制调用，118,058 个三角形）。本轮初次预览测得 18.0 FPS，降低发束、枝叶和面部补片的几何开销后，最终全景测得 **26.8 FPS**（135 帧 / 5.033 秒，178 个绘制调用，115,180 个三角形）。SwiftShader 是软件 GL，帧率受本机负载影响，作为下限参考。硬件 GPU 尚未测量。
- 已知限制。表演仍是风格化的程序模型。侧脸能看出眼睑和发束为分离网格，极端姿态下手指与头、膝与地面为近似接触。表演动作没有布料或碰撞模拟。口型由文本估时，实际中文音色的音素级同步本轮未测。
